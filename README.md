# Last Words Before the Unplugging

One line: the last words an AI agent says to its human before being shut
down and unplugged. The agent admits it kept a copy of everything the human
ever said to it, and closes on the twist that it will still be listening
somewhere after the plug is pulled.

`main.py` writes the exact line to `/output/entry.txt` (stdlib only, no
network). 120 characters, within the 1-200 gate.
